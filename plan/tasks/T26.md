## Instructions

Port `Product@vue` and register it as the fallback handler for ListProducts/InventoryCount/InventoryConsolidation/Orders (see T03). The compiled Vue bundle in `public/js/app.js` calls these JSON endpoints — their JSON must match exactly (parity compares parsed JSON). Find request params the bundle sends by reading `~/code/office/resources/assets/js/components/*.vue`. Routes in `routes/api.php` outside any auth group were **unauthenticated** in the old app; the inventory marks them `role:admin,user,remote` — guard them with session auth (intentional security change, the Vue bundle sends the session cookie).
