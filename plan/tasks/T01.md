# T01 — Views engine, Blade helper globals, layouts

Phase: 0. Depends on: T00.

Read `plan/CONVENTIONS.md` and `plan/PLAN.md` first. Old app: `~/code/office` (read-only). Work in `~/code/office_new`.

## Instructions

Build `src/view.ts` and port the shared layouts so later tasks only port page bodies.
1. Nunjucks env over `views/`, autoescape on, `throwOnUndefined: false`. `render(req, reply, name, data)` injects:
   `auth` ({user, roles}), `errors` (Laravel MessageBag API: has/first/get/all/any/count), `session(key)`, `old(key, def)`.
2. Globals mimicking PHP/Laravel exactly (each with a vitest test comparing to known PHP output):
   url(path, params?) [absolute APP_URL-based like Laravel `url()`], asset(path), route(name, params?) [uses named route
   table from src/router.ts — stub the import if router isn't built yet], csrf_token(), csrf_field() [`<input type="hidden" name="_token" value="...">`],
   method_field(m), config(key), trans(key) [port `~/code/office/resources/lang/en/*.php` to `src/lang/en.ts`],
   date(format, ts?) [PHP date() format chars], number_format(n, dec=0, dp='.', ts=','), round, substr, explode, implode,
   count, strtoupper, ucfirst, json_encode [PHP escaping: `\/`, unicode \uXXXX], in_array, isset, phpEmpty, nl2br, e, hasRole(roles).
3. laravelcollective/html 5.2 `Form::` and `HTML::` helpers used in views (grep `Form::` and `HTML::` across
   `~/code/office/resources/views`; implement only the methods used: open, close, model, text, textarea, select, hidden,
   checkbox, submit, label, token…). Emit identical HTML (attribute order matters — read
   `~/code/office/vendor/laravelcollective/html/src/FormBuilder.php`).
4. Port these layouts/partials to `views/` (same relative path, `.njk`): every view that is `@extends`-ed or `@include`-d
   by a routed view. Find them: grep `@extends(`/`@include(` across the views listed in `plan/inventory.json`'s controllers
   (`views` field). At least: `layout`, `unshipped_layout`, `layouts/app`, `layouts/app1`, `includes/header`, `includes/nav`,
   `partial/*`, `scaffold-interface/layouts/app`, `scaffold-interface/layouts/defaultBootstrap`, `errors/*`, `error/*`.
   Where a layout reads data (nav counts, user name, notifications), find where PHP provides it (View composers in
   `app/Providers`, or `Auth::user()` in the layout) and provide it from `render()`.
5. Test: a test route `/__layout-test` (dev only, behind `NODE_ENV!=='production'`) rendering a page extending `layout`.
Verify: typecheck, tests. Note any PHP construct you could not map in STATUS.md.
