# L09 — Houzz + Wayfair clients

Phase: 3. Depends on: T00, T01, T02, T03, T04.

Read `plan/CONVENTIONS.md` and `plan/PLAN.md` first. Old app: `~/code/office` (read-only). Work in `~/code/office_new`.

## Instructions

Port `app/Libraries/Houzz.php, Wayfair.php.` to `src/lib/`.
- Keep function names (camelCase) and return shapes identical to what callers expect. Grep callers across `~/code/office/app` to see which methods are actually used; port only those (list skipped ones in STATUS.md).
- Credentials: copy the needed env var names from `~/code/office/.env` / `config/*.php` into `.env.example` (names only) and `.env` (values).
- Every outbound call goes through one `request()` function per lib so tests can mock it. Add a `DRY_RUN=1` env switch that logs instead of sending for any **write** call (purchase, upload tracking, inventory/price updates, fulfill).
- vitest: mock HTTP, assert request URL/body/headers for each ported method against what the PHP would send.
