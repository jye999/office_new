# T02 — Auth: login/logout/register/password reset, roles, PDA api-key

Phase: 0. Depends on: T01.

Read `plan/CONVENTIONS.md` and `plan/PLAN.md` first. Old app: `~/code/office` (read-only). Work in `~/code/office_new`.

## Instructions

1. Sessions: @fastify/secure-session (key from APP_KEY, cookie `office_session`, httpOnly, sameSite lax) + @fastify/flash.
2. `src/auth.ts`: `currentUser(req)` loads `os_users` row (minus password/remember_token) + role names via
   `os_user_has_roles` ⨝ `os_roles` (cache on req). `hasRole(user, role|roles)`. Guard factory `requireRoles(roles)`:
   no user → 302 to `/login` (remember intended URL like Laravel `redirect()->guest`), user without any role → 403 body `No Access.`.
3. Routes from Laravel 5.4 `Route::auth()` (see vendor/laravel/framework/src/Illuminate/Routing/Router.php `auth()`):
   GET/POST /login, POST /logout, GET/POST /register, GET /password/reset, POST /password/email,
   GET /password/reset/{token}, POST /password/reset — with names login, logout, register, password.request,
   password.email, password.reset. Port views `auth/login`, `auth/register`, `auth/passwords/email`, `auth/passwords/reset`.
   Login field is `email` (AuthenticatesUsers default) — confirm in `app/Http/Controllers/Auth/LoginController.php`.
   Password check: bcryptjs.compare(plain, hash.replace(/^\$2y\$/, '$2a$')). On success redirect to intended or `/home`.
   Failed login: redirect back with `errors.email = trans('auth.failed')` and old input — same as Laravel.
   Laravel throttles login (5 tries/min) — replicate with an in-memory counter.
   Register / password reset: port behaviour (check RegisterController — it may be disabled/redirecting); password reset
   email sending must be behind a `MAIL_ENABLED` flag defaulting to off.
4. `pdaAuth` preHandler = port of `app/Http/Middleware/AuthenticateApiKey.php` (Bearer / X-Api-Key / api_key input,
   sha256 → `os_user_api_tokens.token_hash`). Same 401 JSON bodies.
5. `auth:api` (api.php group: /api/logout, /api/user, /api/settings/profile, /api/settings/password, /api/pda/api-key):
   find out how the Vue bundle authenticates (grep `Authorization`, `access_token`, `localStorage` in
   `~/code/office/resources/assets/js`; check `config/auth.php` api guard driver — passport or jwt). Implement the same
   mechanism against the existing `os_oauth_*` tables / JWT secret so the existing compiled `public/js/app.js` keeps working.
   Document the decision in STATUS.md. If it's Passport personal tokens, validate by looking up the token id in
   `os_oauth_access_tokens` (JWT signed with `~/code/office/storage/oauth-public.key`).
6. `GET /`, `/home` → port HomeController@index role-based redirect logic (it's tiny) so login can be tested end-to-end.
Verify: tests for bcrypt $2y$ verification and role guard; manual: log in with PARITY_EMAIL on :7000.
